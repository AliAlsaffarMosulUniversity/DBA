# BA-DMS — النسخة السحابية المخففة 3.0

الإصدار النشط هو [cloud](cloud/README.md)، ويعمل على **Cloudflare Workers + Firebase**، مع حفظ الشفرة هنا على GitHub. لا يحتاج حاسبة مستخدم أو خادم جامعة.

- ملفات التدريسيين والإضافة والتعديل والصلاحيات.
- تبليغات وروابط مرفقات وتأكيد اطلاع مستقل.
- إدخال جداول دراسية وامتحانية وفحص تعارضاتها واعتمادها ونشرها.
- أزيل التوليد التلقائي بـOR-Tools والاعتماد على Python وDocker من النسخة السحابية.

إعداد Cloudflare Builds: Root directory = `cloud`. باقي الإعدادات في [الدليل](cloud/README.md).

لم يُتحقق بعد من النشر الفعلي. الملفات القديمة الموجودة في جذر المستودع، ومنها backend وcompose، تخص النسخة المحلية السابقة ولا تستخدم في تشغيل الإصدار السحابي. لا ترفع بيانات القسم أو مفاتيح الخدمة إلى GitHub.
